Uma base aberta

O mesmo cofre, nos seus termos.

O Passage aproveita o formato e as ferramentas do GNU pass. Use o mesmo cofre no terminal, no desktop Linux e nas extensões para Brave e Chrome.

01 / FORMATO

Arquivos GPG

Consulte, crie e edite entradas compatíveis com GNU pass. A chave privada permanece no seu dispositivo.

02 / CONTROLE

Git sob sua escolha

Publique ou clone seu cofre em um Git privado. O desktop permite registrar, baixar e enviar alterações.

03 / TERMINAL

Sem trocar seu fluxo

O GNU pass continua funcionando diretamente no terminal. O Passage é uma interface adicional para o mesmo formato.

Versão inicial

Experimente no Linux.

O instalador baixa o release Linux x86_64, verifica seu SHA-256 e instala o aplicativo no seu usuário. Não é necessário clonar o repositório.

$ curl -LsSf https://passage.plu.nz/install.sh | sh

Requer GNU pass configurado e as bibliotecas gráficas do Tauri. Revise o script antes de executá-lo.

MVP Linux

Onde estamos.

O desktop gerencia o cofre GNU pass e sincroniza com Git. As extensões para Brave e Chrome são carregadas uma vez em cada navegador, pareadas individualmente e preenchem logins após sua escolha.

  • Desktop: entradas, TOTP, Git e controle das extensões.
  • Navegadores: teste de formulários em Brave e Chrome estável com perfis descartáveis.
  • Depois: biometria, cliente web independente e aplicativo Android próprio.
