Your vault stays yours.

Passage is an interface for GNU pass vaults. Your secrets stay in your GPG files, and you choose where to sync your private Git repository.

An open foundation

The same vault, on your terms.

Passage uses the GNU pass format and tools. Use the same vault in the terminal, on Linux desktop, and in the Brave and Chrome extensions.

01 / FORMAT

GPG files

Read, create, and edit GNU pass entries. Your private key stays on your device.

02 / CONTROL

Your choice of Git host

Publish or clone your vault using a private Git repository. The desktop can commit, pull, and push changes.

03 / TERMINAL

Keep your workflow

GNU pass still works directly in the terminal. Passage is another interface for the same vault.

Early release

Try it on Linux.

The installer downloads the Linux x86_64 release, verifies its SHA-256 checksum, and installs Passage for your user. You do not need to clone the repository.

$ curl -LsSf https://passage.plu.nz/install.sh | sh

Requires GNU pass, GPG, GTK3, and WebKit2GTK 4.1. Review the installer script before running it.

Linux MVP

Where we are.

The desktop manages the GNU pass vault and syncs it with Git. Brave and Chrome extensions are loaded and paired separately in each browser, then fill logins when you choose an entry.

  • Desktop: entries, TOTP, Git, and extension access controls.
  • Browsers: tested forms in Brave and stable Chrome using disposable profiles.
  • Later: biometrics, an independent web client, and a dedicated Android app.
